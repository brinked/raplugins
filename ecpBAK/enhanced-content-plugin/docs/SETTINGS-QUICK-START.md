# Multi-Author Plugin Settings - Quick Start Guide

## 🚀 Getting Started in 3 Steps

### Step 1: Access Settings
1. Log in to WordPress admin
2. Go to **Settings → Multi-Author**

### Step 2: Customize
Choose what you want to change:
- **Role Labels**: Change text like "Written by", "Co-Author", etc.
- **Styling**: Adjust sizes and colors

### Step 3: Save
Click **Save Settings** button at the bottom

---

## 📝 Role Labels

Change the text displayed for each contributor role:

| Setting | Default | Example Alternative |
|---------|---------|-------------------|
| Written By | "Written by" | "Author:", "By", "Authored by" |
| Co-Author | "Co-Author" | "With", "Contributing Author" |
| Reviewed By | "Reviewed by" | "Edited by", "Reviewed by" |
| Fact-Checked By | "Fact-Checked by" | "Verified by", "Fact-checked by" |

---

## 🎨 Styling Options

### Sizes

| Setting | Range | Default | Recommended |
|---------|-------|---------|-------------|
| Avatar Size | 30-150px | 60px | 50-80px |
| Name Font | 10-30px | 16px | 14-18px |
| Title Font | 10-24px | 14px | 12-16px |
| Label Font | 10-20px | 12px | 11-14px |

### Colors

| Setting | Default | Purpose |
|---------|---------|---------|
| Name Color | #000000 (Black) | Contributor names |
| Title Color | #666666 (Dark Gray) | Job titles |
| Label Color | #999999 (Light Gray) | Role labels |

**Tip**: Click any color field to open the color picker!

---

## 💡 Quick Tips

### ✅ Do's
- ✅ Keep labels short and clear
- ✅ Maintain good color contrast
- ✅ Test on mobile devices
- ✅ Match your site's style
- ✅ Save after each change

### ❌ Don'ts
- ❌ Don't use very small fonts (<12px)
- ❌ Don't use low-contrast colors
- ❌ Don't make avatars too large (>100px)
- ❌ Don't forget to save changes

## 🔧 Troubleshooting

### Settings Not Saving?
1. Check you're logged in as admin
2. Clear browser cache
3. Try a different browser

### Changes Not Showing?
1. Clear all caches
2. Verify you're viewing a post (not page)
3. Check post has contributors assigned

### Color Picker Not Working?
1. Update WordPress to 5.0+
2. Enable JavaScript
3. Clear browser cache

## ⚡ Pro Tips

1. **Preview Changes**: Save and view a post to see changes immediately
2. **Color Matching**: Use your browser's color picker on your site to match colors
3. **Responsive Testing**: Check on mobile after making size changes
4. **Backup First**: Note current settings before major changes
5. **Start Small**: Change one thing at a time to see the effect

## 🎓 Example Workflow

1. **Access**: Settings → Multi-Author
2. **Change Label**: "Written by" → "By"
3. **Save**: Click Save Settings
4. **Test**: View a post with contributors
5. **Adjust**: Return to settings if needed
6. **Repeat**: Continue customizing
